코드는 어떻게 작성하고 사용하였는가

2026.09.26 실험 · 한국어 웹 이미지의 그림 설명과 OCR 비교

새 모델을 학습한 것이 아니라, 공개 모델을 비교하는 실행 코드를 작성하였다

이미지 한 장을 열어 그림 설명 모델과 OCR에 각각 전달하고, 두 결과를 출처별로 저장하였다. 이후 파일을 모아 비교 화면과 보고서를 만들었다. 이번 공개 저장소에는 당시 실험 코드와, 팀원이 경로를 지정해 다시 실행할 수 있는 진입점을 구분해 넣었다.

단계코드가 하는 일주요 파일
입력 준비이미지 포맷·방향·투명도를 확인하고 모델 입력으로 바꾼다.inspect_data.py / prepare_subset.py
그림 설명Patch-ioner 또는 Florence가 전체·영역 설명을 생성한다.run_patch_batch.py / run_florence.py
글자 읽기EasyOCR·PP-OCRv5가 원문·좌표·score를 반환한다.run_easyocr.py / run_paddle.py
보완 비교작은 입력 확대, 배경 변경, 큰 이미지 타일을 적용한다.run_enhanced_ocr.py / run_paddle_enhanced.py
집계선택한 72문구가 각 출력에 포함되는지 계산한다.scripts/score_saved.py
화면 구성저장된 JSON과 이미지로 보고서·예시·검색 화면을 만든다.당시 결과 통합 코드 / 현재 결과 데이터 갱신 코드

팀원이 바로 다룰 코드는 src에 따로 두었다

Florence와 PaddleOCR는 필요한 라이브러리가 다르다. 한 환경에 억지로 합치지 않고, 조정 프로그램이 각 환경의 Python을 순서대로 실행하도록 구성하였다. 실제 모델 계산은 각 worker가 수행하고, 마지막에 두 출력을 모은다.

입력 → 처리 → 저장의미
이미지 → Florence → caption.json전체 그림·사진 설명을 저장한다.
같은 이미지 → PP-OCRv5 한국어 → ocr.json인식한 글자와 원본 좌표를 저장한다.
두 출력 → evidence.jsonLLM에 전달할 후보 정보를 출처별로 모은다.
두 출력 + 입력 이미지 → result.html사람이 이미지를 보면서 비교할 수 있는 화면을 만든다.
  • 실행 인자에서 모델 위치·캐시·Python 경로·장치를 지정한다. 개인 PC 경로를 코드에 고정하지 않는다.
  • 이미지 설명과 OCR를 한 문장으로 합쳐 정답처럼 만들지 않는다. 충돌과 오류를 검토할 수 있도록 원문을 분리한다.
  • OCR score는 그 엔진이 반환한 값이다. 정답 확률이나 서로 다른 모델 간 비교 점수로 취급하지 않는다.
  • 이 진입점은 한 장의 기본 추출을 위한 것이다. 299개 전체 재실험, 모든 전처리 변형, Gemma 판정까지 자동 실행하는 프로그램은 아니다.

결과를 저장하고 화면에 보여주는 방식

  • data/sample_results.json은 299개 이미지별 모델 출력·점검 메모를 한곳에 묶은 열람용 데이터이다.
  • results.html은 같은 JSON을 페이지 안에 포함한다. 다른 파일을 요청하지 않고 검색·선택을 처리하며, OCR 좌표는 이미지 위에 도형으로 겹쳐 표시한다.
  • 웹 문맥에는 기존 alt와 주변 글이 포함된다. 비전 모델 실행에는 넣지 않았고, 후속 LLM 입력용 파일에서 별도 필드로 보관하였다.
  • data/evidence_packets.jsonl에는 대회 정답 label과 시각 평가 판정·참조 문구를 넣지 않았다.
  • 정답 label은 원본 데이터와 분포 확인용으로만 따로 제공한다. 최종 분류 모델의 입력으로 그대로 전달하면 안 된다.

기록용 코드와 실행용 코드를 구분하였다

  • experiments/snapshots/는 당시 일괄 실험 코드이다. 원래 작업 폴더 구조와 Patch-ioner 별도 소스에 의존한다. 원클릭 재현용으로 표시하지 않았다.
  • experiments/report_builders/는 보고서 생성·수정 과정의 코드이다. 현재 공개 HTML 파일이 팀에서 읽고 수정할 기준본이다.
  • src/의 새 실행 진입점은 Florence + 한국어 OCR에 범위를 한정하여 경로 설정을 받도록 정리하였다.
  • 모델 가중치·가상환경·개인 경로는 저장소에 포함하지 않았다. 사용한 모델·패키지 설정은 실행 안내와 manifest에 기록하였다.
