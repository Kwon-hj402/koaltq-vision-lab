# KoAltQ 샘플 데이터셋 (문제발굴 신청용, 299쌍)

한국어 공공 웹 대체텍스트 품질 판정 데이터셋의 신청 시점 샘플. 채택 시 동일 형식으로 3,000쌍을 공개한다.

## 구성

- `records.jsonl`: 레코드 299건 (1행 1레코드, UTF-8)
- `images/`: 레코드별 이미지 파일
- `라벨링-가이드라인-v0.2.md`: 라벨 판정 기준, 경계 사례 규칙, 개정 이력

## 수집·라벨링 방법

- 수집: 공공기관 웹사이트 8곳(정책브리핑, 보건복지부, KISTI, 대구시, 대구 동구청, 대전중구청, 국립중앙도서관, 안동시)에서 alt 속성이 존재하는 이미지를 문맥 메타데이터와 함께 수집 (robots.txt 준수, 2026-08-25~26)
- 라벨링: AI(VLM) 사전 라벨 생성 후 접근성 전문가(WCAG 2.2/KWCAG 2.2 기반 검사 서비스 운영)가 전수 검수·확정. 판정 보류 1건은 제외. AI 사전 라벨과 전문가 확정 라벨의 불일치는 300건 중 78건(26.0%)
- 저작권: 공공누리 표시 페이지 우선 수집, `kogl_marker` 필드로 구분. 라벨·메타데이터는 CC BY

|---|---|---|---|

| image_url | 원본 이미지 URL | String | |
| image_file | images/ 내 파일명 | String | |
| alt_text | 원본 대체텍스트 (원문 그대로) | String | 빈 문자열 포함 |
